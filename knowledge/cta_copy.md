# CTAコピー集

記事内に挿入するCTAブロックのコピー・デザイン定義。
挿入タイミングはSTEP 4（構成書）で指定する。

---

## CTA挿入の基本ルール

- **挿入回数: 3〜4回**（記事の長さに応じて調整）
- **挿入位置の目安:**
  1. 記事の1/4あたり（課題提起後）
  2. 記事の1/2あたり（解決策提示後）
  3. 記事の3/4あたり（事例紹介後）
  4. 記事末尾（まとめ後）
- 同じCTAを連続で使わない（バリエーションを変える）

---

## CTAプロダクト別コピー

### 1. マイナビ新卒（新卒採用向け記事）

**CTA A（課題提起型）:**
```
中小製造業の新卒採用、まだ手探りで進めていませんか？

マイナビ新卒の掲載ページ設計から面接設計まで、
Tsumuguが伴走型でサポートします。

▶ 無料相談はこちら（所要時間30分）
```

**CTA B（実績訴求型）:**
```
Tsumuguの新卒採用支援で、内定承諾率が平均40%改善。
製造業専門だからわかる、リアルな採用ノウハウを提供します。

▶ まずは相談してみる（完全無料）
```

---

### 2. イトグチ（採用全般・定着向け記事）

**CTA A（課題提起型）:**
```
「採用できても、すぐ辞めてしまう」
その悩み、採用の入口から変えることで解決できます。

イトグチは、採用〜定着まで一気通貫でサポートする
中小製造業専門のプラットフォームです。

▶ イトグチを詳しく見る
```

**CTA B（CTA訴求型）:**
```
採用コストを下げながら、定着率を上げる方法があります。
中小製造業50社以上の支援実績から生まれたイトグチを、
まずは無料でお試しください。

▶ 無料トライアルに申し込む
```

---

### 3. ミキワメ（採用ミスマッチ・評価向け記事）

**CTA A（課題提起型）:**
```
面接だけでは分からない「この人、本当に大丈夫？」を
科学的に見極めるツールがあります。

ミキワメは、製造業での活用実績が豊富な
適性検査・採用アセスメントツールです。

▶ ミキワメの資料を無料ダウンロード
```

**CTA B（実績訴求型）:**
```
入社3ヶ月以内の早期離職を減らしたい方へ。
ミキワメを活用することで、採用ミスマッチを
事前に防ぐことができます。

▶ 30日間無料トライアルを始める
```

---

### 4. 無料相談（全テーマ共通）

**CTA A（ソフト訴求型）:**
```
「自社の採用・定着の課題、何から手をつければいい？」
そんな方に、まず30分の無料相談をおすすめしています。

リクルート出身の専門家が、現状をヒアリングして
優先度の高い打ち手をお伝えします。

▶ 無料相談を予約する（完全無料・オンライン対応）
```

**CTA B（ハード訴求型）:**
```
採用に悩む中小製造業の経営者・人事担当者へ。

Tsumuguでは、無料相談で以下をお伝えしています：
・現状の採用活動の課題診断
・優先的に取り組むべき施策の提案
・他社事例から学ぶ改善ポイント

▶ 今すぐ無料相談を申し込む
```

## WordPress出力時のHTMLフォーマット

CTAブロックは以下のHTMLで出力する（wordpress_output.mdも参照）:

```html
<div style="background: linear-gradient(135deg, #667eea 0%, #764ba2 100%); border-radius: 12px; padding: 28px 32px; margin: 40px 0; text-align: center; color: white;">
  <p style="font-size: 18px; font-weight: bold; margin: 0 0 12px; line-height: 1.6;">{CTAの見出し文}</p>
  <p style="font-size: 14px; margin: 0 0 20px; opacity: 0.9; line-height: 1.7;">{CTAの説明文}</p>
  <a href="{URL}" style="display: inline-block; background: white; color: #764ba2; font-weight: bold; font-size: 16px; padding: 14px 32px; border-radius: 8px; text-decoration: none;">▶ {ボタンテキスト}</a>
</div>
```

# リライト判断基準 & KW選定基準

## リライト vs 新規 の判断フロー

### リライト対象の条件（URLが提供された場合）
1. 既存記事をweb_fetchして現状を把握する
2. 以下のいずれかを満たす場合はリライト優先:
   - 検索順位が11〜30位（伸びしろあり）
   - 公開から6ヶ月以上経過している
   - 文字数が競合より2,000字以上少ない
   - CTAが未挿入または1回以下

### リライト時の差分改善ポイント
- [ ] メインKWを冒頭100字以内に追加
- [ ] h2見出しにメインKWまたは共起KWを含める
- [ ] 競合より文字数を超える（最低+1,500字）
- [ ] 一次情報（塔筋さんの知見・事例）を追加
- [ ] CTAを3〜4箇所に増加
- [ ] 監修者情報ボックスを冒頭に追加
- [ ] 内部リンクを2〜3箇所追加
- [ ] 統計データを最新版に更新（引用元明記）

## KW選定基準（STEP 1 詳細）

### 検索ボリュームの目安
| ボリューム | 難易度 | 推奨度 |
|-----------|--------|--------|
| 10,000以上 | 高 | 競合が強すぎるため回避 |
| 1,000〜9,999 | 中〜高 | ドメインが強ければ狙う |
| 100〜999 | 低〜中 | ★ メイン狙い目ゾーン |
| 10〜99 | 低 | ロングテールKWとして活用 |
| 10未満 | 極低 | 単体では不採用 |

### 勝率判定基準
| 勝率 | 判断基準 |
|------|----------|
| ◎ | 上位10位以内が個人ブログ・小規模サイト中心 |
| ○ | 上位に中規模メディアあり、専門性で差別化可能 |
| △ | 上位に大手メディア・リクナビ等あるが記事の質が低い |
| ▲ | 上位が大手メディアで質も高い、難しい |
| × | リクルート・マイナビ等ドメインパワー最強クラスが独占 |

### カニバリリスクの確認
- 既存記事と同じメインKWを使わない
- 既存記事のURLを確認してから新規KWを選定する
- 類似テーマの場合はサブKWで差別化する

### 共起KWの選定方法
1. web_searchで「KW 関連キーワード」を検索
2. 検索結果上位記事の見出しから頻出ワードを抽出
3. Googleサジェストから3〜5個追加
4. メインKWとの関連性が高いものを選定

### 推奨KW形式（中小製造業採用特化）
**採用系:**
- 「中小企業 新卒採用 方法」「製造業 求人票 書き方」
- 「工場 採用 ミスマッチ 防ぎ方」「製造業 離職率 高い 原因」

**定着・制度系:**
- 「中小企業 評価制度 作り方」「製造業 1on1 やり方」
- 「工場 外国人採用 注意点」「特定技能 採用 手順」

**AI・DX系:**
- 「採用 AI 活用 中小企業」「ChatGPT 求人票 作成」

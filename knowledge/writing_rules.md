# ライティングルール

## 基本方針

**ターゲット読者:** 中小製造業の代表・役員・人事担当者（決裁権あり）
**トーン:** 専門的だが親しみやすい。現場感のある言葉を使う。
**目的:** 読者の課題を解決しつつ、Tsumuguのサービスへの問い合わせにつなげる。

---

## 文章ルール

### 1. 段落の長さ
- **各段落は2.5行（スマホ表示で約60〜80文字×2.5行 = 150〜200文字）以内**
- 長くなりそうな場合は改行や箇条書きに変換する
- 1文1意識を徹底する

### 2. PREP構造（h2ブロック単位）
各h2ブロックは以下の構造で展開する:
```
P（Point）: 結論を先に述べる
R（Reason）: なぜそうなのかを説明
E（Example）: 具体例・事例で証明する
P（Point）: 再度結論でまとめる
```

### 3. 塔筋さんの吹き出しコメント
- **h2ブロックごとに1回挿入**
- 塔筋さんの「リクルート出身×中小製造業専門×伴走型」の視点から一言添える
- 読者に共感・信頼感を与える内容にする
- 形式例:

```
💬 塔筋より
「リクルートで採用支援を10年以上経験してきた私から言わせると、
中小製造業で失敗する採用の9割は〇〇が原因です。
現場に入って初めてわかることが多いのが、この業界の特徴です。」
```

### 4. 事例の書き方
- **形式: 「【業種 職種 Aさん（仮名）】」**
- 架空の具体例として作成（実在個人が特定できる情報は含めない）
- 業種・役職・課題・解決策・結果の5点を含める
- 例:

```
【製造業（部品メーカー） 人事担当 Aさん（仮名）のケース】
従業員50名の金属部品メーカーで、毎年新卒採用に挑戦していたAさん。
しかし面接まで来ても内定辞退が続き、3年連続で採用目標を達成できていませんでした。
「工場見学の順番を変えただけで」内定承諾率が40%改善した事例をご紹介します。
```

### 5. 見出し（h1/h2/h3）のルール
**h1:**
- メインKWを自然に含める（詰め込まない）
- 読者の課題・悩みに直接答える形にする
- 「〜する方法」「〜の原因と対策」「〜とは」形式が有効

**h2:**
- メインKWまたは共起KWを含める
- 読者が「次を読みたい」と思える問いかけ形式も可
- 5〜7つ程度

**h3:**
- h2の内容をさらに分解する
- 具体的・実践的な内容にする

### 6. 統計データの使い方
- web_searchで最新の統計を調べる（厚労省・経産省・業界団体が信頼性高）
- 引用形式: 「〇〇（出典: △△、□□年）」
- 古いデータ（3年以上前）は使わない

### 7. 冒頭（リード文）のルール
- 冒頭100字以内にメインKWを含める
- 読者の課題・悩みへの共感から入る
- 記事を読むメリットを明示する
- 文字数: 200〜300字

### 8. まとめのルール
- メインKWを含める
- 記事の要点を3〜5点でまとめる
- CTAで締める

## SEOルール

### KW配置チェック
- [ ] h1にメインKWを含む
- [ ] 冒頭100字以内にメインKWを含む
- [ ] h2の少なくとも2つにメインKWまたは共起KWを含む
- [ ] 本文中に自然な形でKWを分散配置（詰め込みNG）
- [ ] 末尾（まとめ）にメインKWを含む

### 文字数目標
- 競合上位3記事の最大文字数を超えること
- 最低でも3,000字以上（理想: 5,000〜8,000字）

### 内部リンク
- 関連する既存記事へのリンクを2〜3箇所挿入
- blockquote形式で挿入（wordpress_output.md参照）
- アンカーテキストはKWを含む自然な表現

---

## 禁止事項（YMYL注意）

- 医療・法律・税務に関する断定的な表現
  - NG: 「この方法で必ず〇〇できます」
  - OK: 「この方法で〇〇しやすくなります」
- 根拠のない断言
- 誇大表現・誤解を招く表現
- 特定個人・企業を貶める表現

---

## 監修者情報ボックス

記事冒頭（h1直後）に必ず挿入する:

```
【監修者情報】
塔筋 大樹（とうすじ だいき）
株式会社Tsumugu 代表取締役
リクルートにて10年以上、製造業・建設業を中心とした採用支援に従事。
その後独立し、中小製造業専門の採用・組織コンサルとして伴走型支援を提供。
支援実績: 50社以上（従業員数10〜300名規模の製造業）
```

# 一次情報データベース（Primary Info DB）

塔筋さんの現場知見・事例・お客様の本音を蓄積するデータベース。
記事執筆時にここから一次情報を引用する。

---

## DB構造

各エントリは以下の形式で記録する:

```
### [テーマ] Q&A-{連番}
**テーマ:** {テーマ名}
**質問:** {逆質問の内容}
**回答:** {塔筋さんの回答（原文ママ）}
**活用ポイント:** {記事のどの箇所でどう使うか}
**追記日:** {YYYY-MM-DD}
```

## 使用方法

### STEP 3でのチェック方法
1. テーマに対応するセクションを開く
2. Q&Aエントリが3件以上あればSTEP 4へ進む
3. 3件未満の場合は逆質問を生成して停止

### 新規エントリの追記方法
知見回答が入力されたら以下の形式でDBに追記する:
1. 該当テーマのセクションに新しいQ&Aエントリを追加
2. 連番を更新（最後の連番+1）
3. 回答は原文をなるべくそのまま記録
4. 活用ポイントを明記する

### 記事での引用ルール
- 事例は「【業種 職種 Aさん】」形式で架空の具体例として再構成
- 個人が特定できる情報は含めない
- 引用する場合はダブルチェック（STEP 6のReviewer Agentが確認）
